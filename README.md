# Husjagt 🏡

Privat overblik over villaer til salg i Svenstrup/Godthåb (9230) og Støvring (9530).

- `scripts/hent_huse.py` henter huse fra Boligsiden og Boliga.
- GitHub Actions kører det hver morgen og ved klik på **Actions → Hent huse → Run workflow**.
- Siden ligger i `docs/` og vises via GitHub Pages.

Standardkrav (kan ændres på siden): min. 150 m², 5 værelser, 2 badeværelser, bygget 1990 eller senere, maks. 4 mio. kr.
